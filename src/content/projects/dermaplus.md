## Resumen del Proyecto
Desarrollé la landing page de DermaPlus como una experiencia web elegante y moderna para una clínica dermatológica premium. El sitio está diseñado como una SPA estática con navegación suave, hero de video de fondo, secciones de servicios animados y un formulario de contacto de alta conversión.

## Arquitectura y Retos Técnicos
Para lograr una experiencia visual cuidada y de alto rendimiento, apliqué las siguientes decisiones técnicas:

- **Next.js App Router + exportación estática:** El proyecto se construye como un sitio SPA estático listo para desplegar en cualquier hosting sin servidor.
- **Chakra UI personalizado:** Creé una identidad visual consistente usando temas y componentes reutilizables, con soporte responsive desde móviles hasta escritorio.
- **Animaciones avanzadas:** Usé `Framer Motion` para dar vida al hero, a los carruseles de servicios y a las transiciones de las secciones.
- **Interacción con usuario:** Implementé un formulario de contacto validado con UX animada, y botones de llamada a la acción estratégicos para agendar citas.
- **Dashboard de métricas internas:** Incluí una ruta de panel (`/dashboard`) para mostrar un resumen de métricas y visualizaciones, reforzando la experiencia de producto más allá de la landing.

## Resultados
- Diseño atractivo que transmite confianza y profesionalismo dermatológico.
- Experiencia fluida y accesible en dispositivos móviles y desktop.
- Arquitectura limpia basada en componentes y hooks para mantener el proyecto escalable.
- Entrega de una landing lista para presentar el servicio de la clínica y generar leads.

## Detalles Adicionales
- Animaciones suaves con `framer-motion`.
- Formulario de lead con validación y estados de envío.
